# PROOFLOOP Backend

Backend API starter for PROOFLOOP.

## API endpoints

- `GET /` — Server status
- `GET /api/health` — Health check
- `POST /api/test` — Test a JSON request

## Deployment

Build command: `npm install`

Start command: `npm start`

The server uses the hosting platform's PORT environment variable.

Note: This starter backend does not yet include the AI app-building engine.
